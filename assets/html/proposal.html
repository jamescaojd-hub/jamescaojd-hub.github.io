Attribution Graph 到底准不准：用干预实验检查

1. 执行摘要

Attribution graph 不能只看起来合理，还要经得起实验检验。它说某个 feature 很重要，我们就把这个 feature 临时关掉；如果模型对目标答案的信心真的明显下降，说明 graph 的判断比较可信。反过来，如果关掉后几乎没变化，说明这张 graph 可能只是“画得像解释”，但没有真正抓到模型在用的东西。

我们做了一个轻量级验证流程：对每个 prompt 先生成 attribution graph，再按 attribution score 选出一批 feature，逐个把它们置零，最后看 target token 的 logit 掉了多少。当前主实验已跑完 40 个 case，覆盖 factual recall、copying / induction、simple reasoning 和 complex reasoning 四类任务，每类 10 个 case；此外又参考 attn-tracer/scripts/run_complex_cases.py 追加跑完 20 个更强的 complex / attention / negation stress cases。

目前最有价值的发现不是“graph 永远正确”，而是它在哪些地方会出错：有些高分 feature 关掉后影响不大；有些 random feature 反而也很重要；复杂推理可能不是靠单个 feature 完成，而是分散在一组 features 里。把这些失败情况整理清楚，可以反过来指导下一步怎么改进 circuit tracing 和 attention-aware attribution。

2. 研究动机：解释不能只靠看图

如果 graph 说某个 feature 或 edge 很重要，那么我们动它的时候，模型输出就应该有明显变化。

所以，本项目不是再提出一种新的画图方法，而是检查现有 graph 说得准不准。相比原始 Circuit Tracing 论文里偏个案展示的验证方式，这里更关心三个直接问题：

  1. attribution score 高的 feature，关掉后影响是不是真的更大；
  2. attribution graph 是否比 random、activation magnitude、activation × gradient 这些简单方法更有用；
  3. graph 在不同任务上是否一样可靠，尤其是在强依赖 attention 或组合推理的任务上会不会明显变差。

如果验证成立，attribution graph 就可以作为定位关键 feature、edge 或 routing mechanism 的工具；如果验证失败，失败本身也有价值，因为它会告诉我们当前方法哪里不够好，比如 fixed-attention graph 是否漏掉了 QK attention routing，或者 graph 是否把 value flow、attention routing 和 activation magnitude 混在了一起。

3. 评估设计

3.1 实验设计

图 1. 从 attribution graph 到因果干预验证的整体流程。

分析单元 graph 中被选中的单个 feature。

表 1. 评估设计：把 attribution graph 的静态重要性分数转化为可干预、可聚合的因果验证流程。

更具体地说，每个 case 固定做三步：

  1. 按 graph 选 feature：从 attribution graph 中抽取和 target logit 相关的 features，按 abs(attribution score) 排序，再取 top / middle / bottom 三组。
  2. 逐个置零：每次只动一个 feature activation，保持 prompt、target token、模型权重和其他 feature 不变。
  3. 看是否对得上：在同一 prompt 内比较 graph score 与 abs(logit drop)，再看 top features 是否明显强过 random / activation-based baselines。

这种设计的好处是简单、可复现，而且能直接回答一个核心问题：graph 排名前列的 feature，关掉后是不是真的更有影响。局限也很明确：它只检查单个 feature，不能证明整个 circuit 或 attention routing 都已经被解释清楚。

3.3 评估指标

指标 定义 解释

3.4 对照方法与判断标准

为了避免自说自话，我们把 attribution graph 和三类简单 baseline 放在一起比较：

Baseline 控制的替代解释 重要性
Random graph feature 随机选择 graph 中的 feature。 检查 top attribution 是否真的比随便选更好。
Activation magnitude 选择 activation 最大的 feature。 排除“只是因为这个 feature 激活更大”的解释。
Bottom / middle attribution feature 选择低分或中等分 graph feature。 检查 attribution score 是否真的有排序意义。

标签 MVP 阶段的判断标准 解释
Strong support Pearson / Spearman 为正，且 top-random gap 与 top-activation gap 都明显大于 0（通常 > 0.5 logit）。 graph 的判断和真实干预结果基本一致。

4. MVP 结果：哪里有效，哪里失败

我们已经在 circuit-tracer 上跑通第一版 MVP。本轮实验用的是 CPU 环境和小规模配置（batch_size=16，max_feature_nodes=100，top_k=2）。目标不是给出最终结论，而是先确认这套评估流程能跑通，并观察初步趋势。

由于当前 AttributionTargets 要求 string target 被 tokenize 成单个 token，MVP 中所有 target 都选成单 token，例如 " Paris"、" C"、" Texas"、" three"。

MVP 的核心信号很清楚：在 factual / lexical continuation 任务上，attribution graph 通常能找对重要 feature，而且强过 random 和 activation-magnitude baseline；但在 arithmetic reasoning 上，这种优势最不稳定，这是目前最明确的失败边界。追加的 20-case stress test 进一步细化了这个结论：分布式算术里 arithmetic_fraction_logic 的 top-random gap 为 -0.013，而 attention routing、compositional reasoning 和 negation / constraints 组整体仍有正向 baseline advantage。

5. 结果解读：失败案例告诉我们什么

  • 算术是最清楚的失败边界。 arithmetic_reasoning_remaining 的 Pearson 为 -0.057、top-random gap 为 0.004、Top-activation gap 为 -0.041；arithmetic_reasoning_three 的 Top-activation gap 也接近 0。这说明当前 graph 还不能稳定找到数量组合相关的关键 features。下一步应优先检查：算术机制是否分散在很多 features 里、单 feature 置零是否太局部、CLT feature 是否没有对齐算术变量。
  • 当前 graph 可能解释不了 attention 为什么这样走。 现在的 attribution graph 更像是在解释固定 attention pattern 下的信息流，而不是解释 QK attention routing 是怎么形成的。Copying / induction 虽然整体结果不错，但它仍不一定说明“模型为什么会看向那个位置”。下一步需要引入 attention-aware QK attribution，把 value-flow attribution 和 attention-routing attribution 分开看。
  • 不能只看 Pearson，要看 graph 是否真的强过简单 baseline。 有些 case 的 Pearson 很高，但 top-random gap 很小，例如 copy_sequence_animals。这说明 graph 内部排序可能看起来不错，但 random baseline 或 activation magnitude baseline 也能达到类似效果。后续主指标应同时看 rank correlation、top-random gap、top-activation gap 和 baseline advantage。

6. 当前局限与改进方案

当前 MVP 已经证明评测流程可行，但它还只是第一版小规模实验。主要限制和后续处理方式如下：

威胁 当前风险 缓解方案
样本规模较小 主实验覆盖 40 个 case，追加 stress test 覆盖 20 个 case，但每组 feature 当前仍只取 top_k=2。 每类扩展到 30–100 cases，将 top_k 提高到 10–20，并报告 bootstrap confidence interval。
局部 node-level ablation 只关掉单个 feature，可能低估由多个 features 共同完成的机制。 扩展到 edge-level / path-level intervention，并测试 grouped feature ablation。
单 token target MVP 只选择单 token target；多 token answer 和 sequence-level behavior 尚未覆盖。 引入 sequence-level metrics，并处理 multi-token target 的 attribution aggregation。
Graph pruning max_feature_nodes=100 便于快速实验，但可能丢掉弱而关键的中间路径。 在 GPU 环境下提高 graph budget，并比较不同 pruning threshold 下的结果稳定性。
Baseline 尚不完整 当前已有 random、bottom / middle、activation magnitude；activation × gradient、integrated gradients、edge-level baselines 尚未系统加入。 引入 gradient-based baselines，并报告 baseline-adjusted faithfulness score。
单一 model / feature space 当前结果基于 Gemma-2-2B 与对应 transcoder features，尚不能直接推广。 跨模型、跨 feature dictionary 复现实验，区分模型特定边界和 tracing 方法边界。

8. 预期贡献

本项目的贡献可以概括为三点：

  1. 给 attribution graph 做“体检”：graph 说哪个 feature 重要，就真的去动哪个 feature，看模型输出是否变化。
  2. 加入更公平的 baseline 对照：不只看 Pearson / Spearman，还要看 top features 是否强过 random 和 activation magnitude baseline。
  3. 找出 graph 的适用边界：它在 factual / lexical continuation 上较可靠，但在 arithmetic / compositional reasoning 和潜在 attention-routing 任务上更不稳定。

9. 相关工作

本项目建立在 circuit tracing 和 sparse feature circuits 的基础上，但关注点不是“怎么画出 attribution graph”，而是“这张 graph 说的重要 feature，实验上是否真的重要”。也就是说，一个 graph 不仅要能展示 computation，还要能预测哪些 features 真正控制目标输出。
